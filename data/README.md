# PLEASE READ

The data needed to run the code in the `python` folder is originally from the paper *Reservoir Computing for Macroeconomic Forecasting with Mixed Frequency Data (2024)* available at

**https://github.com/RCEconModelling/Reservoir-Computing-for-Macroeconomic-Modelling**

## Folder Structure

The following folder structure is assumed:

```
data/
 |- dfm_medium/
 |   |- ...
 |- dfm_small/
 |   |- ...
```

The full dataset is not available due to licensing restrictions on the daily data obtained sourced from Datastream.
