B=1 GDP figures used in the revised manuscript
=============================================

medium/ contains 28 panels for Figures 1, 2, I.1-I.3 and I.8-I.9.
small/ contains 16 panels for Figures I.4-I.7.
Each PDF is one panel; the manuscript arranges the panels into figures.
Plots not displayed in the manuscript are omitted from this folder.

Sources and settings
--------------------
Medium-MD: python/ensemble_multistep_medium_md.py, results_rev1/
Small-MD:  python/ensemble_multistep_small_md.py, results_small_rev1/

These PDFs were generated by the plotting sections of the corresponding
main scripts, using the saved B=1 expert forecasts. Forecast combinations
were recomputed with the repository's comb_multistep_funcs.py, including
the corrected DecHedge and AdaHedge routines. The evaluation covers all
48 quarters, 2008Q1-2019Q4, at h=1. The expert pools contain K=1000 models.
Raw squared-error losses, eta=c0=10000 and RollMSE r=4 are unchanged.
The Simple Average legend is SA. FTL panels retain the scripts' original
leader-index line plots; this export does not change their plotting style.

No fitting/forecasting helpers, main scripts, saved results or old figures
were overwritten for this export. Only plotting flags and save destinations
were overridden for the export run. The calculations use repository files;
the numerical checks also compare against the previously verified results.

Regeneration
------------
Use the Python environment described by the repository requirements. Run
each main script from the python/ directory, with these settings:

    FORECAST_STEPS = 1
    DO_FORECASTS = False
    DO_PLOTS = True
    OPTIONAL_PLOTS = False
    SAVE_PLOTS = True
    SAVE_RESULTS = False
    SAVE_CSVS = False

The standard script destinations are figures_multistep_rev1/ (Medium-MD)
and figures_multistep_small_rev1/ (Small-MD). The scripts produce additional
diagnostic plots. To reproduce this manuscript-only package, retain the
panels listed below and apply the five filename aliases before copying them
to figures_rev1/medium/ or figures_rev1/small/. These plotting settings do
not require refitting the experts or the original predictor/DFM data files.
Full estimation from scratch still requires the separate source datasets.

Filename convention
-------------------
The PDF filenames below match the manuscript's includegraphics basenames,
so they can be copied into its plots_rev1_update/ folder without changing
the TeX references. Keep M-MFESN_A in the scripts and model identifiers.
Five manuscript references use the older spelling M-MFESN-A instead. Only
the exported filenames use that spelling, for these panels:

    Figure 1(c):   ecdf_M-MFESN_A_multistep_h=1_seed_MediumMD_fix_2007.pdf
    Figure I.1(c): ecdf_by_leak_rate_M-MFESN_A_multistep_h=1_seed_leak_MediumMD_fix_2007.pdf
    Figure I.2(c): ecdf_M-MFESN_A_multistep_h=1_seed_leak_MediumMD_fix_2007.pdf
    Figure I.4(c): ecdf_M-MFESN_A_multistep_h=1_seed_SmallMD_fix_2007.pdf
    Figure I.5(c): ecdf_M-MFESN_A_multistep_h=1_seed_leak_SmallMD_fix_2007.pdf

For these five source filenames only, replace M-MFESN_A with M-MFESN-A.
No other filenames change. In particular, the lambda, alpha_lambda and
weight-dynamics filenames keep M-MFESN_A. Do not rename files to figure
numbers: those numbers can change when the manuscript is rearranged.
